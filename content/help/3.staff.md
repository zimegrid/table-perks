## Steps

1. Open **Branch Management → Staff**.
2. Click **Add Staff** in the top right corner.
3. Enter the staff name, email, password, role, and branch.
4. Set **Active** to ON and click **Add Staff**.

## Example Data

| Field | Value |
|---|---|
| Full Name | Ahmed Hassan |
| Email | manager@rozana.com |
| Password | Rozana123 |
| Role | Branch Manager |
| Branch | Rozana Restaurant - Lilburn |

## Recommended first staff

Create a **Branch Manager** first. This gives the merchant a reliable admin-level user for day-to-day operations.
