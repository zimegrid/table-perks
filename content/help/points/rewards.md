## Steps

1. Open **Points → Rewards**.
2. Click **Add Reward** in the top right corner.
3. Select the **Reward** (a menu item), then enter the **Reward Name** and **Description**.
4. Set **Points Required** and upload a **Reward Image**.
5. Set **Active** to ON and click **Create Reward**.

## Example Data

| Field | Value |
|---|---|
| Reward Name | Free Latte |
| Reward (Menu Item) | Latte |
| Points Required | 150 |
| Active | Enabled |
