## Steps

1. Open **Points → Tier**.
2. Click **Add Tier** to create your base tier first. The base tier's **Minimum Points** must be 0, and it can't be deleted later.
3. Enter a short **Title** (e.g. "Bronze"), choose a **Theme**, and write a **Description**.
4. Set the **Points Multiplier** — how much faster customers earn points once they reach this tier.
5. Set **Minimum Points** required to reach this tier. It must be higher than every tier below it.
6. Optionally add **Benefits** — an icon, title, and description for each perk this tier unlocks.
7. Click **Create Tier**, then repeat to add higher tiers (e.g. Bronze → Silver → Gold).

## Example Data

| Field | Value |
|---|---|
| Title | Silver |
| Points Multiplier | 1.25x |
| Minimum Points | 500 |
| Benefit | Priority support — "Get faster responses from our support team" |

## Why this step matters

Only one tier can have Minimum Points set to 0 — that's your base/default tier every customer starts in. Set it up before creating any higher tiers.
