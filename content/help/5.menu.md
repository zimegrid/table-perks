## Steps

1. Open **Menu Management → Menu Items**.
2. Click **Add Menu** in the top right corner.
3. Enter item name, description, image, price, and category.
4. If needed, add **Variants** for item options such as size or flavor.
5. Set the item to **Active** and save.

## Example Menu Items

| Field | Value |
|---|---|
| Item | Hummus Plate |
| Category | Appetizers |
| Price | $8.99 |
| Variant Example | Latte → Small / Medium / Large |

## Best practice

For Greggs-style item loyalty, create item-specific menu entries such as **Coffee**, **Breakfast Roll**, and **Dessert** so the stamp logic can match merchant products more clearly.
