## Steps

1. From the left sidebar, open **Branch Management → Branches**.
2. On the Branches page, click the **Add Branch** button in the top right corner.
3. Complete the branch form including branch name, address, optional order URL, and map location.
4. Set **Active** to ON. Use **Main Branch** only if this is the primary location.
5. Click **Add Branch** to save.

## Example Data

| Field | Value |
|---|---|
| Branch Name | Rozana Restaurant - Lilburn |
| Address | 4800 Lawrenceville Hwy A1, Lilburn, GA 30047 |
| Order URL | https://rozanarestaurantdemo.com/order |
| Active | Enabled |
| Main Branch | Enabled (if primary) |

## Why this step matters

Staff and role assignments depend on at least one branch being available. Always create the primary branch before staff setup.
